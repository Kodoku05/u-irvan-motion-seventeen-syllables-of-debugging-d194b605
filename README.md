A Node 22 standard-library program that writes one haiku about debugging — three lines in the 5-7-5 syllable shape — to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The output directory defaults to `/output`. The program creates it when needed.
